# 02. Jira Installation and Cloud Setup

## Deployment Options

| Option | Who hosts it | Notes |
|---|---|---|
| **Cloud** | Atlassian | Sign up and use it in the browser. Always on the latest version |
| **Data Center** | Your company | Self-managed on your own servers or private cloud, for large regulated organisations |
| **Server** | Your company | The older self-hosted edition. Atlassian **ended support for Server in February 2024** |

New teams should start on **Cloud**.

## Cloud Plans

Pricing page: https://www.atlassian.com/software/jira/pricing

| Plan | Typical use |
|---|---|
| **Free** | Up to 10 users, enough for learning and small teams |
| **Standard** | Growing teams that need user roles and permissions |
| **Premium** | Advanced planning, higher limits, guaranteed uptime |
| **Enterprise** | Many sites, central security and compliance controls |

> Limits and prices change over time, so check the pricing page before choosing a plan for a real team.

## Setting Up a Free Jira Cloud Site

1. Open https://www.atlassian.com/software/jira/free and choose **Sign up**.
2. Sign up with your email (or a Google or Microsoft account) and **verify** the email address Atlassian sends you.
3. Choose your **site name**. It becomes your Jira address, for example `your-domain.atlassian.net`. You'll use this URL in every Python script later.
4. Answer the short onboarding questions (team type, what you work on). They only pre-select templates.
5. Create your first **project**:
   - Template: **Scrum** (sprints) or **Kanban** (continuous flow). Topic 03 explains the difference.
   - Type: **Team-managed** (simple, configured by the team) or **Company-managed** (configured by Jira admins, shared schemes). The admin topics (06 and 07) use company-managed projects.
   - Name: for example `cloudops_cloud`, with the **key** `AC`.
6. Click **Create**. Jira opens the new project's board.

## Project Keys

Every project has a short **key**, and every issue key starts with it:

| Project | Key | Issue keys |
|---|---|---|
| myproject | `MYP` | `MYP-1`, `MYP-2`, `MYP-8` |
| IT-Infra-project | `IIP` | `IIP-1`, `IIP-24` |
| Python Project | `PP` | `PP-10`, `PP-11` |

> Choose keys carefully. Scripts, JQL queries and links all use them, and renaming a key later leaves old links redirecting to the new one.

## Your Work Page

After signing in you land on **Your work** (`https://your-domain.atlassian.net/jira/your-work`). It lists the issues assigned to you, recently viewed items and your projects. It's the best starting page every morning.
