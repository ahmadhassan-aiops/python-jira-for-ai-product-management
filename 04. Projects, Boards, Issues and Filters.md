# 04. Projects, Boards, Issues and Filters

## Project vs Board

These two are easy to mix up:

| | Project | Board |
|---|---|---|
| What it is | A **folder** or group that owns issues, settings and permissions | A **view**: a place where issues are displayed in columns |
| Relationship | One project can have **many** boards | A board can show issues from a filter, often from one project |

So a project and a board are **not** a one-to-one relationship. You can switch between a project's boards (for example a *Dev board* and a *QA board*) from the board selector.

## Anatomy of an Issue

Open any issue (for example `PP-10`) and you'll see:

| Section | Contents |
|---|---|
| **Header** | Project, issue key, summary (the title) |
| **Description** | The full details of the request |
| **Sub-tasks** | Smaller pieces, each with its own assignee and status |
| **Activity** | Comments, History (every change) and Work log (time spent) |
| **Status button** | The current status. Click it to move the issue along its workflow |
| **Details panel** | Assignee, reporter, labels, story points, sprint, fix version, priority, time tracking |

### Sub-tasks for Teams

When two teams work on the same story, split it:

```text
PP-10  Story: Course page becomes visible to enrolled students
 ├── PP-11  Sub-task (Team 1, Frontend): show the course card     DONE
 └── PP-12  Sub-task (Team 2, Backend): return enrolled courses   IN PROGRESS
```

The story shows **50% done** until both sub-tasks reach *Done*.

## Creating Issues Quickly

- Press **C** anywhere in Jira to open the **Create** dialog.
- Pick the project and issue type, enter a summary, and click **Create**.
- Useful keyboard shortcuts: **/** focuses search, **M** opens a comment box on an issue, **?** lists every shortcut.

## Basic Search and Filters

**Filters > Search issues** (sometimes shown as *View all issues*) opens the search page.

1. Use the dropdowns at the top: **Project**, **Type**, **Status**, **Assignee**, and **+ More** for any other field.
2. Type words into **Contains text** to search summaries, descriptions and comments.
3. Click **Search**. The table lists matching issues with key, summary, assignee, status and dates.
4. Click **Save as** (or **Save filter**) to keep the search as a named **filter**. Saved filters can feed dashboards, boards and email subscriptions.

### Built-in Filters

| Filter | Shows |
|---|---|
| My open issues | Unresolved issues assigned to you |
| Reported by me | Issues you created |
| All issues | Everything you can see |
| Open issues | Every unresolved issue |
| Done issues | Issues in a done status |
| Viewed recently / Created recently | Your history and new issues |

> When the dropdowns can't express what you need, switch to **JQL**, the Jira Query Language. That's the next topic.
